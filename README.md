# PixelArt

Редактор пиксельных изображений на C# / .NET 10 / WinForms. Основная логика находится в отдельной библиотеке без зависимости от Windows и интерфейса.

## Быстрый запуск

Готовая автономная сборка на этом компьютере: `artifacts/PixelArt/PixelArt.App.exe`. Ее можно открыть двойным щелчком, установка .NET для нее не нужна. Папка `artifacts` не включается в Git: сборка создается скриптом `publish.ps1`.

Запуск из исходников (Windows, установленный .NET 10 SDK):

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

Без параметров открывается главный экран с кнопками создания/импорта и карточками проектов. Кнопка «+» подключает папку с проектами без копирования, список рядом переключает папки. «Импортировать» по-прежнему создает отдельную копию файла. Сразу открыть пример:

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1 .\samples\landscape.pixelart
```

Скрипты учитывают SDK в `%USERPROFILE%\.dotnet`, если он установлен локально. Для Visual Studio 2026 откройте `PixelArt.sln`, выберите `PixelArt.App` стартовым проектом и нажмите F5. Тестовые проекты запускаются отдельно.

## Возможности

- Главный экран: создание/импорт, превью проектов, дата изменения, переименование и удаление.
- Несколько папок проектов: подключение через «+», переключение, отключение без удаления, поиск во вложенных папках.
- Автосохранение в выбранную папку, возврат из редактора на главную, внешние копии и проверка внешнего изменения файла перед записью.

- Холст 1–256 пикселей по каждой стороне, прозрачность и собственная палитра каждого проекта: начальные 16 цветов, добавление своих (до 256), редактирование двойным щелчком.
- Кнопки инструментов с иконками и подсказками; фигуры собраны в выпадающее меню.
- «Смещение пятна» (S): аналог по смыслу Blender Smear — перенос и смешивание цветов холста, круглая кисть 1–32 px, сила 0–100%.
- Карандаш и ластик с независимыми размерами 1–32 px, заливка и пипетка; после выбора пипеткой автоматически включается карандаш. Линия, прямоугольник, эллипс и рисуемая сетка.
- Контурные и закрашенные фигуры, предпросмотр, 100 действий отмены/повтора.
- Масштабирование колесом к указателю; панорамирование через пробел + ЛКМ, среднюю кнопку или инструмент «Рука».
- Повороты ±90°, сдвиг содержимого, включаемая пиксельная сетка.
- Проекты `.pixelart` (JSON), импорт PNG/JPEG/BMP/GIF и буфера обмена, экспорт PNG с размером пикселя 1–16.
- Горячие клавиши и F1-справка, пользовательские настройки, пакетный CLI без окна.

## Кисть «Смещение пятна»

Нажмите S или кнопку с пальцем. При выборе появятся размер и сила: начальные значения — 8 px и 80%. Зажмите ЛКМ на окрашенном участке и протяните через другой цвет или в прозрачную область. Выбранный основной цвет не используется; щелчок без движения не меняет картинку. Сила задается числом, не нажимом планшета.

100% сильнее тянет подхваченную краску, меньшие значения постепенно смешивают ее с цветами под кистью. Штрих отменяется одним Ctrl+Z, Esc отменяет незавершенный. Настройки кисти запоминаются в пользовательских настройках; полученные пиксели сохраняются в проекте. Это собственная упрощенная реализация, не точный движок или импорт пресета Krita.

## Где проекты и как сохранять

По умолчанию проекты хранятся в `%LOCALAPPDATA%\PixelArt\Projects`. На главном экране можно нажать «+» и подключить другую папку, например каталог Google Drive для компьютера. Приложение ищет `.pixelart` и совместимые `.json` внутри нее, включая подпапки. Обычные посторонние JSON игнорируются. Список папок и последний выбор запоминаются при нормальном выходе из приложения.

Подключение не копирует файлы: редактирование найденного проекта сохраняет изменения прямо в исходный файл. Создание нового проекта и «Импортировать» записывают новый проект в текущую выбранную папку. Импорт отдельного файла не меняет оригинал. «−» только отключает папку от списка; кнопка «Удалить» на карточке действительно удаляет проект с диска.

После завершения действия изменения автоматически сохраняются примерно через 1,5 секунды. `Ctrl+S` сохраняет немедленно. «Главная», `Ctrl+Home` или закрытие редактора сохраняют проект и возвращают к карточкам. `Ctrl+Shift+S` записывает отдельную внешнюю копию `.pixelart`, `Ctrl+E` экспортирует PNG. Ошибка автосохранения видна в строке состояния; при неудачном сохранении перед закрытием можно остаться в редакторе.

Для Google Drive/OneDrive установите клиент синхронизации, подключите нужную папку и сделайте проекты доступными офлайн. Синхронизацию выполняет клиент, не редактор; вход в Google из приложения не нужен. F5 или «Обновить» перечитывает проекты. При отключении диска папка остается в списке, но создание/импорт блокируются, пока она недоступна.

Если файл изменился снаружи после открытия, редактор остановит запись и предложит сохранить внешнюю копию. Это проверка содержимого, а не распределенная блокировка: не редактируйте один проект одновременно на двух компьютерах и делайте резервные копии. Удаление из синхронизируемой папки может передаться в облако.

## Проверка и сборка

```powershell
powershell -ExecutionPolicy Bypass -File .\test.ps1
powershell -ExecutionPolicy Bypass -File .\publish.ps1
```

`test.ps1` собирает решение и запускает два набора: 59 проверок библиотеки и 38 проверок Windows-приложения. Во время UI-проверок ненадолго появляются тестовые окна.

## Пример командной строки

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1 .\samples\landscape.pixelart --export .\artifacts\large.png --scale 8
```

Для воспроизводимой демонстрации из Python есть `examples/demo.ipynb`.

Подробное описание классов, алгоритмов, формата, запуска и проверки — в [info.md](info.md). Документация до добавления главного экрана сохранена в `info.before-home-screen.md`.
