# PixelArt

Редактор пиксельных изображений на C# / .NET 10 / WinForms. Основная логика находится в отдельной библиотеке без зависимости от Windows и интерфейса.

## Быстрый запуск

Готовая автономная сборка на этом компьютере: `artifacts/PixelArt/PixelArt.App.exe`. Ее можно открыть двойным щелчком, установка .NET для нее не нужна. Папка `artifacts` не включается в Git: сборка создается скриптом `publish.ps1`.

Запуск из исходников (Windows, установленный .NET 10 SDK):

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

Сразу открыть пример:

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1 .\samples\landscape.pixelart
```

Скрипты учитывают SDK в `%USERPROFILE%\.dotnet`, если он установлен локально. Для Visual Studio 2026 откройте `PixelArt.sln`, выберите `PixelArt.App` стартовым проектом и нажмите F5. Тестовые проекты запускаются отдельно.

## Возможности

- Холст 1–256 пикселей по каждой стороне, прозрачность и палитры 2/4/16/256 цветов.
- Кнопки инструментов с иконками и подсказками; фигуры собраны в выпадающее меню.
- Карандаш и ластик с независимыми размерами 1–32 px, заливка и пипетка; линия, прямоугольник, эллипс и рисуемая сетка.
- Контурные и закрашенные фигуры, предпросмотр, 100 действий отмены/повтора.
- Масштабирование колесом к указателю; панорамирование через пробел + ЛКМ, среднюю кнопку или инструмент «Рука».
- Повороты ±90°, сдвиг содержимого, включаемая пиксельная сетка.
- Проекты `.pixelart` (JSON), импорт PNG/JPEG/BMP/GIF и буфера обмена, экспорт PNG с размером пикселя 1–16.
- Горячие клавиши и F1-справка, пользовательские настройки, пакетный CLI без окна.

## Проверка и сборка

```powershell
powershell -ExecutionPolicy Bypass -File .\test.ps1
powershell -ExecutionPolicy Bypass -File .\publish.ps1
```

`test.ps1` собирает решение и запускает два набора: 34 проверки библиотеки и 19 проверок Windows-приложения. Во время UI-проверок ненадолго появляются тестовые окна.

## Пример командной строки

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1 .\samples\landscape.pixelart --export .\artifacts\large.png --scale 8
```

Для воспроизводимой демонстрации из Python есть `examples/demo.ipynb`.
